# Simple Interest Calculator

A simple tool to calculate simple interest based on principal amount, annual interest rate, and time period.

# Formula
The formula used to calculate simple interest is:

$$A = P (1 + rt)$$

Where:
- **P** = Principal amount
- **r** = Annual interest rate (in decimal form, e.g., 5% = 0.05)
- **t** = Time period (in years)
- **A** = Total amount (Principal + Interest)

#Example Usage
- **Principal (P):** $1,000
- **Rate (r):** 5% per year (0.05)
- **Time (t):** 2 years

### Calculation:
$$Simple\ Interest = P \times r \times t = 1000 \times 0.05 \times 2 = \$100$$
$$Total\ Amount = 1000 + 100 = \$1100$$
